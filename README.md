# Gourish Kumawat — Portfolio

Personal portfolio and résumé website, built with plain HTML, CSS and vanilla JavaScript. No build step, no dependencies.

One continuous page that reads as a short story: an illustrated Gourish waves hello, the top of his head lifts open as you scroll, and the page dives inside. Hero → Now → About → Education → Experience → Work (VittamHub + RUHS research + DEV Herbal) → Achievements → Skills → Interests → Contact.

## Keeping it current

**Résumé.** Three links point at `assets/documents/Gourish_Kumawat_Resume.pdf` — the nav button, the hero CTA and the contact card. Replace that one file to update all three. Keep the filename exactly as-is.

**Profile photo.** `assets/images/profile.jpg`, portrait orientation (the frame crops to 4:5). If the file is missing the hero falls back to a marked placeholder rather than breaking.

**Cache busting.** `index.html` loads `style.css?v=3` and `script.js?v=3`. GitHub Pages lets browsers cache those files for about 10 minutes, so bump the number whenever either file changes, or visitors may get the new page with old styles.

**Deployment URL.** `index.html` sets `<link rel="canonical">` and the Open Graph tags to `https://gourishkumawat9.github.io/gourish-portfolio/`. If the site is deployed anywhere else, update those three URLs — otherwise link previews will point at the wrong place.

## Running locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`. Opening `index.html` directly also works, though the résumé download behaves better over HTTP.

## Design system — "Inside the mind"

Defined in custom properties at the top of `style.css`:

- **Surfaces** — night-sky periwinkle (`--sky`) for the hero, Work and Contact; a deeper indigo (`--mind`) for everything "inside the head". The opening in the illustration is filled with `--mind`, so the hero can grow it into the next section without a seam.
- **Accent** — one warm marigold (`--marigold`), kept for small labels, the scroll playhead and the Interests band. Mint is only the "open to internships" dot; the blue (`--select`) is only the design-tool selection box.
- **Type** — Italiana (display), Bebas Neue (labels and nav), Antonio (condensed reading lines), Schibsted Grotesk (body). Italiana has old-style numerals, so `Youth4Water` wraps its 4 in `.digit`.
- **Texture** — an animated SVG-noise film grain over the whole page; twinkling stars are generated by `script.js` from `data-stars` counts.
- **Hard shadows, no blur** — the polaroid, the field-notes ticket and the browser frame use flat offset shadows.

## Motion

All in vanilla JS and CSS; there are no libraries.

- **Hero scroll scene** — the hero is 300vh with a sticky stage. Scroll progress is smoothed, then drives: the name lifting away, the lid of the head lifting (`.character__lid`), seven "thought" chips fanning out (desktop positions are `data-x/y` in units of the figure width; phones use hand-placed `data-m` pixel offsets), a dive toward the opening, and finally `.portal` — an ellipse clip-path that starts exactly over the opening and grows past the corners.
- **Ambient details** — the waving arm, blinking eyes, pupils that follow the pointer, birds, the selection box that measures the name live, and a roaming "Gourish" cursor.
- **Sections** — titles split into letters that rise in, staggered reveals, count-up stats, a tilting product screenshot, magnetic buttons, an Interests marquee, and the character peeking up at Contact.
- **Scroll ruler** — a fixed tick-mark ruler at the bottom with section labels placed at their real scroll positions and a marigold playhead.
- **Sound** — off by default. When toggled on it plays a soft WebAudio chord with occasional chimes. It is synthesised, so there are no audio files.

`prefers-reduced-motion` turns all of this off: the hero stays one screen tall, the lid sits slightly ajar, and every section renders in its final state.

## Accessibility

Audited with axe-core (WCAG 2.1 A/AA + best practice) at 1440px, 820px and 390px (the last with reduced motion): **0 violations**. Notable choices:

- The bottom ruler duplicates navigation, so it is `aria-hidden` and its links carry `tabindex="-1"`.
- Split-letter titles keep the real text in an `.sr-only` span; the animated letters are `aria-hidden`.
- The illustration has a `<title>`; the thoughts, stars, birds, cursor and grain are decorative and hidden from assistive tech.
- The sound button uses `aria-pressed` with a stable name ("Sound"); the on/off word is visual only.
- Without JavaScript every section is visible, and controls that need script are hidden.
